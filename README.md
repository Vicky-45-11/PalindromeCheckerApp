# PalindromeCheckerApp

A simple application that checks whether a word, phrase, or number reads the same forwards and backwards.

## About

A palindrome is text that stays the same when reversed, such as "madam" or "121". This app takes an input, cleans it up, and tells you whether it is a palindrome.

## Features

- Checks words, phrases, and numbers
- Ignores case, spaces, and punctuation
- Gives a clear result: palindrome or not

## Getting Started

Clone the repository:

git clone https://github.com/Vicky-45-11/PalindromeCheckerApp.git
cd PalindromeCheckerApp

Then build and run the app using your usual setup for this project.

## Example

Input: A man, a plan, a canal: Panama
Output: Palindrome

Input: hello
Output: Not a palindrome
